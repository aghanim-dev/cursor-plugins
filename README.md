# Aghanim Cursor Marketplace

A [Cursor plugin marketplace](https://cursor.com/docs/plugins#team-marketplaces)
containing Aghanim's plugins for Cursor.

## Plugins

| Plugin | Description |
| --- | --- |
| [`newton`](plugins/newton/README.md) | Search Aghanim's docs and the Aghanim public API via the Newton MCP server, plus a webhook quick-start skill. |
